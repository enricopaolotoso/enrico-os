# Security Policy

## Reporting A Vulnerability

If you notice a security issue involving this website or repository, please contact:

**enricopaolotoso@gmail.com**

Please include:

- a short description of the issue;
- steps to reproduce it;
- affected URLs or files;
- any relevant screenshots or logs.

Do not publicly disclose security issues before they have been reviewed.

## Secrets

Spotify credentials and SiteGround deployment credentials must only be stored as local environment variables or GitHub Actions secrets. They must never be committed to the repository.
